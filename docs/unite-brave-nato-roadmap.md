# Дорожная карта к UNITE – Brave NATO

> Рабочий документ, не публичный. Основан на открытых источниках на
> 2026-08-07. Перед подачей — сверяться с актуальным порталом
> `unite-brave-nato.brave1.tech`, не с этим файлом.

## 0. Почему это, а не DIANA напрямую

DIANA требует, чтобы компания была majority owned by nationals of NATO member
nations — при украинском мажоритарном владельце это, по всем найденным
источникам, не проходит независимо от места регистрации. UNITE–Brave NATO с
самого начала построена как пара «украинская компания + компания из страны
NATO» — украинская компания в ней полноправный участник по дизайну программы,
а не обходной манёвр. Подробности разбора DIANA — `docs/diana-grant-roadmap.md`.

## 1. Механика программы

- **Формат:** обязательная пара — 1 украинская компания + 1 компания из страны
  NATO. Соло заявки не подаются.
- **Портал:** `unite-brave-nato.brave1.tech` — matchmaking-система для поиска
  партнёра, не просто форма подачи заявки.
- **Деньги:** до €250,000–500,000 на партнёра (контрактное финансирование под
  совместный продукт, не «просто грант на развитие» как Phase 1 у DIANA).
- **Отбор в два этапа:**
  1. Expression of Interest — квалификационная проверка на соответствие
     критериям → попадание в Register of Qualified Applicants.
  2. Полная совместная заявка — уже вдвоём с партнёром.
- **Администрирование:** через украинскую систему Prozorro.

## 2. Жёсткие дисквалификаторы — проверить в первую очередь, это бесплатно

- [ ] Убедиться, что ни у одного бенефициара компании нет связей с РФ/Беларусью.
- [ ] Убедиться, что нет связей со страной из чёрного списка FATF.
- [ ] Проверить, не финансировался ли уже этот же проект через Brave1 напрямую
      (нельзя дважды на один и тот же проект).

## 3. Главная проблема прямо сейчас: тематика раундов

- **Раунд 1** (28 июля – 3 августа 2026, уже закрыт) — фокус: counter-UAV,
  ПВО, защищённая связь на передовой ("secure frontline communications").
  AEGIS — API security, не дрон-технология; прямого попадания нет.
- **Объявленные будущие темы** (после масштабирования до €50 млн): signals
  intelligence, устойчивая навигация в условиях РЭБ, безэкипажные наземные
  системы. Тоже не прямое попадание, но "устойчивость инфраструктуры под
  РЭБ/кибератакой" — ближе, чем чистый counter-drone.
- **Вывод:** нет открытого раунда, который сегодня прямо подходит под AEGIS.
  Это ожидание следующего раунда с подходящей темой, а не немедленная подача.

## 4. Что делать прямо сейчас (не дожидаясь подходящего раунда)

- [ ] **Зарегистрироваться на портале** `unite-brave-nato.brave1.tech` —
      matchmaking может работать не строго по раундам; регистрация заранее не
      стоит ничего и даёт видимость для потенциальных партнёров.
- [ ] **Искать партнёра из страны NATO уже сейчас.** Это обычно самая долгая
      часть процесса — не начинать искать партнёра только после объявления
      подходящего раунда.
- [ ] Пройти дисквалификаторы (раздел 2) — сделать один раз, заранее.
- [ ] Готовить тот же dual-use нарратив, что и для DIANA (см.
      `docs/diana-grant-roadmap.md`, Трек 1) — переформулировка AEGIS под
      защиту API военных/логистических/коммуникационных систем под атакой.
      Он переиспользуется для обеих программ.
- [ ] Следить за анонсами новых раундов через Brave1 (это украинская сторона
      программы, у них должны быть открытые каналы/рассылка).

## 5. Открытые вопросы — нужно узнать напрямую у Brave1, не из новостей

- [ ] Работает ли Register of Qualified Applicants **между** раундами — то
      есть если пройти EOI сейчас без конкретного раунда, действует ли это на
      будущие раунды, или квалификация привязана к конкретному call?
- [ ] Может ли компания искать партнёра до объявления темы раунда, или
      matchmaking открывается только вместе с конкретным call?
- [ ] Насколько узко трактуется тема раунда — принимаются ли заявки, которые
      только частично попадают в объявленную тему (например, "защита API
      систем связи" внутри "secure frontline communications")?

## Риски

- Программа предельно новая (первый раунд — лето 2026), процессы могут
  измениться до следующего раунда.
- Отсутствие открытого раунда под тематику AEGIS может затянуться дольше, чем
  таймлайн в `diana-grant-roadmap.md`.
- Поиск натовского партнёра — отдельный, не короткий процесс, который стоит
  начать параллельно с технической доработкой продукта, а не после неё.
